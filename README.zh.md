# dsh-Websocket

[English](README.md) | 中文

## 概述

通过设置 → WebSocket 网关配置独立命名的 GPT Responses 路由，复制兼容提供商的声明，并查看实际传输与上传大小。WebSocket 可跨同一会话的串行请求保留连接；上下文精确追加时使用 `previous_response_id`，仅发送新增输入。生成前的安全故障可回退 SSE。原提供商、已选模型和子智能体模型权限保持不变。默认 bundle 不声明路由，凭据通过已有服务管理。

## 设置与接入

构建和验证后，通过 Harness 插件管理器安装 bundle。设置 → WebSocket 网关分别提供网关设置和最近请求。可在桌面列表或窄屏选择器选中路由，再编辑连接或模型；高级选项按需展开。保存影响新请求；已接纳和已准备的调用保留原配置。更换凭据不中断活动调用。删除路由不删除历史或原提供商。

导入只预览本地 GPT Responses 模型，不发网络请求。预览标明上下文窗口和输出 Token 上限来自模型显式配置、模型目录、路由默认还是内置默认。可复制兼容来源到 `source-ws` 等新路由，或勾选尚未添加的模型，合并到使用相同端点的现有路由。合并保留目标凭据和设置。不兼容的模型能力或无法解析的限制需要修正后再导入。导入是一次性复制：预览不验证 WebSocket 支持，来源后续变更也不会自动同步。

凭据使用名称引用，设置页可通过 DSH 凭据服务保存替换值。密钥及已保存请求头的值不返回浏览器。请求头编辑器留空保留已有值，`{}` 清空。配置修改检查修订版本，冲突时保留草稿。管理工具 `websocket_gateway` 共用读取、保存、导入、删除、刷新和重置操作；凭据输入与可能计费的验证仅限所有者界面。

已保存并开启模型发现的路由可刷新 `${baseURL}/models`，不发起推理。刷新失败会保留上次成功的目录并提示失败；目录更新后，聊天模型选择器会刷新。显式模型优先于发现的 ID。`discovery.exclude` 只过滤发现结果；移除显式行才会停止显式提供对应模型。模型列表不能确认上下文窗口和思考能力，因此发现使用声明的元数据。显式思考档位优先于可选路由默认值；省略 `reasoning` 不会选择能力列表第一项。

最近请求默认跨网关显示最近五条请求，含辅助调用。可展开列表下方的筛选与刷新选项，或展开任一卡片查看详细诊断。每张卡片显示最终发送的尝试，详情列出每次尝试，包括实际发送的思考档位和输出 Token 上限（如果有）。上游用量分别显示未缓存输入、输出、缓存读取和缓存写入，短横线表示未报告可用值。只有 WebSocket 故障触发的 SSE 才标为回退。每次尝试还记录全量或增量及安全错误码。历史不匹配时显示前缀长度、首个不同的条目类型或白名单字段是否存在，不记录请求数据的值。上传大小统计 UTF-8 应用 JSON，包含回退和续接重建尝试。减少比例将每次已记录尝试与等价全量请求比较，仅覆盖当前保留的最近记录，不含传输帧、握手、TLS，也不是计费估算。刷新状态只读取元数据。显式验证操作先确认授权，再发送两轮小型合成推理，检查随机文本记忆、WS 使用及第二轮增量，不发送聊天历史。

## 续接与隔离

连接按路由配置代次、凭据和请求头身份、模型及会话隔离。没有主会话身份的辅助请求使用单次请求连接。忙碌的会话连接不会共享，并发调用改用独立的完整上下文 SSE 请求。适配器不会把无关响应混入同一个解析器。

首轮发送 pi-ai 序列化后的完整输入。已完成响应的 ID 和输出指纹进入有界内存缓存。后续完整序列化输入必须精确追加在已知输入与输出之后，且请求控制项和工具一致，才能增量发送。比较时归一化已完成函数调用的状态、已解析的函数参数和助手输出文本中的空 `logprobs`，不会改写实际发送的条目。消息 phase、思考签名、非空响应元数据、条目 ID 和数组顺序仍参与比较。未知或不匹配输出、上下文压缩、编辑、图片卸载触发全量重建，不做近似前缀复用。会话历史始终完整且权威。

新连接不假设上一连接的 `store: false` 缓存仍存在。只有生成前明确的 `previous_response_not_found` 拒绝，才允许最多一次全量重发；不确定的断线不允许。连接保留与增量续接分别控制。关闭续接仍可复用 socket，关闭复用则每次请求结束后关闭连接。空闲及最长存活时间回收连接，连接数和历史指纹均有限制。

## 恢复与清理

`auto` 只在生成请求发送前，遇到已识别连接失败、握手超时或 HTTP 404/405/426/501 升级拒绝时回退 SSE。认证、配额、限流和参数错误不切换协议。发送后未确认生成终局，包括部分输出后断线或空闲超时，报告 `OUTCOME_UNKNOWN`：可能已经计费，不静默重发。显式取消仍作为取消处理。

符合条件的 WS 故障即使同次 SSE 回退成功也累计。达到 `fallbackAfterFailures` 后，新尝试在 `fallbackCooldownMs` 内使用 SSE。到期不启动后台任务；下一次请求单独探测 WS，并发请求继续 SSE。WS 成功清零，SSE 成功不清零。认证和配额错误不计入 WS 连接故障。只接受排除未知结果及永久拒绝的有限重试策略，由已有 DSH 重试执行器处理瞬时重试。

WS/SSE 的失败终态或提交请求后收到的独立 WS 错误帧包含 `server_error` 时，报告 `UPSTREAM_SERVER_ERROR`。即使没有收到输出，也不计为连接故障、不切换协议、不自动重发。生成终态报告限流时同样不重发（`UPSTREAM_RATE_LIMIT`）。发送生成请求前，若 WS 升级被 HTTP 5xx 拒绝，仍报告 `SERVER`，可按配置执行有限重试。请求详情只显示允许记录的上游错误码，不保存上游错误原文。

每个请求拥有取消与解析器。成功终态把健康连接归还连接池；取消、消费者返回和失败流关闭相应 socket。卸载插件停止新请求，等待已接纳迭代器，包括暂停消费者，并关闭空闲连接。清理失败显示在诊断和日志中。设置中的重置只关闭空闲连接并清除冷却，不中断活动请求。不替换全局 fetch、dispatcher、WebSocket 构造函数或服务器原型。

## 配置

条目的 `providers` 字典可在线编辑，键是新的提供商 ID，不是原路由别名。每项需要 `baseURL`、`apiKeyEnv`，以及显式 GPT `models` 或 `discover: true`。显式模型需要 `id`、`contextWindow`、`maxTokens`；可选 `input` 默认文本，`reasoningEfforts` 默认无。只接受 `gpt-` 和 `openai/gpt-` ID。模型与路由声明必须符合网关实际能力。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `transport` | `auto` | WS 优先或仅 `sse` |
| `requestFormat` | `standard` | `codex` 将开头的开发者指令编码为带类型的 Responses 输入块，并在有工具时明确声明自动工具选择。网关地址、凭据、会话缓存 key、增量续接和 SSE 回退不变，无需 Codex Connect。`codex-instructions` 从首轮起将首条开发者消息移到顶层 `instructions`，之后每帧（含增量）均发送。请在独立路由上试用；缓存表现取决于上游。 |
| `reuseConnection`、`continuation` | `true` | 独立控制连接保留和增量 |
| `connectionIdleMs`、`connectionMaxAgeMs` | `300000`、`3000000` | 空闲／最长存活，允许配置的最长时间低于 60 分钟 |
| `maxConnections`、`maxContinuationBytes` | `8`、`1048576` | 每个路由代次保留的连接数／每条连接指纹字节 |
| `fallbackAfterFailures`、`fallbackCooldownMs` | `5`、`300000` | WS 故障阈值／SSE 冷却，阈值 0 关闭冷却 |
| `websocketConnectTimeoutMs`、`closeTimeoutMs`、`streamIdleTimeoutMs` | `10000`、`2000`、`300000` | 握手、关闭、响应空闲超时 |
| `maxFrameBytes`、`maxBufferedEvents` | `8388608`、`128` | 接收 WS 帧大小／有界事件队列 |
| `diagnosticsLimit` | `100` | 内存保留的最近请求记录 |
| `discovery.ttlMs`、`discovery.timeoutMs` | `300000`、`10000` | 发现缓存／请求超时 |
| `discovery.contextWindow`、`discovery.maxTokens` | `500000`、`128000` | 发现模型的声明元数据 |
| `discovery.maxResponseBytes`、`discovery.maxModels` | `4194304`、`1000` | 模型发现的响应字节／条目上限 |
| `retryPolicy` | DSH 有限 normal 策略 | 界面提供有限的最大重试次数 |

图片字节、数量、像素限制，自定义请求头，最大输出兼容项和发现元数据在高级区域编辑。配置在注册前校验。未知字段、重复能力、不安全重试码和不被所有模型支持的默认思考档位会拒绝加载或保存。

## 开发与验证

开发依赖链接要求 `<DSH checkout>/local-plugins/plugins/<本目录>` 布局。实现与测试改动全部属于独立插件，不需要修改 DSH 源码。浏览器 factory 使用运行中 GUI 的 React、语言、主题和插槽。仅所有者可访问的认证 Connection 路由与工具调用同一 Host 管理实现。参见[适配器](src/adapter.ts)、[传输](src/transport.ts)、[续接](src/continuation.ts)、[管理](src/management.ts)和[客户端](src/client.js)。

```text
pnpm run build
pnpm run build:check
pnpm test
pnpm run test:profile
pnpm run test:lifecycle
```

`test:lifecycle` 创建带随机标记保护的临时 HMR profile，跨新进程验证安装、旧版升级、安装失败后的恢复、排队保存与卸载竞争、暂停流卸载和移除，不指向当前 GUI profile。默认旧包位于同级 `gpt-ws-gateway`，也可用 `GATEWAY_PREVIOUS_BUNDLE` 指定；`GATEWAY_CANDIDATE_BUNDLE` 可选择已打包的不可变候选。在当前 Windows／pnpm 组合下，测试只为子进程设置 `UV_THREADPOOL_SIZE=1`，规避 pnpm 并行清理父目录的竞态。这是已验证的绕行，不是对 pnpm 的修复，也不能证明运行中原地升级安全。不得自动移除或替换运行中插件；先交付验证后的产物，取得明确部署许可，再计划停进程升级并保留回滚包。

临时 profile 明确拒绝 `@google/genai@2.21.0` 和 `protobufjs@7.6.6` 的安装脚本；它们是与本测试的 OpenAI 链路无关的间接 SDK 依赖，测试不批准脚本。真实安装若尚未决定构建策略，可能停止等待用户选择。不得把测试策略复制进运行中 profile，也不得自动批准构建。

测试使用动态端口的回环 HTTP／WS、确定性冷却时钟、实际 pi-ai 序列化、构建后客户端组件测试，以及临时 profile 的 Loader／管理验证。`test:profile` 使用构建后的 DSH CLI，也可通过 `GPT_GATEWAY_DSH_BIN` 指定入口。虚构 Key 和隔离状态避免真实账号推理。本地测试通过不代表真实网关支持已确认。保留现有图标；[LICENSE](LICENSE)适用于原创插件代码，SDK 保留各自许可。

## 模型体验

提供 tools 的组合会向模型增加有界的管理工具定义，不增加系统提示或用户消息。历史、工具、图片和思考选项仍由 DSH／pi-ai 序列化。WS 与 SSE 使用同一 Responses 解析器。续接改变上传 JSON，不改变权威历史或计费规则。保留 `store: false`。从原适配器切换到新 WS 路由可能使原生回放元数据降级。默认思考档位可能改变延迟和 Token 用量，不保证减少费用或延迟。

## 已知限制

仅支持普通 API Key GPT Responses 路由，不支持 Codex OAuth、仅 Chat Completions 的服务器、其他模型家族、代理或共享 socket 多路并发。导入刻意保守，是快照而不是对其他适配器的实时引用。原提供商保持代理和认证行为；需要代理的路由不得复制到本插件的直连链路。服务端模型能力、WS 缓存寿命和续接兼容性需要针对实际网关验收。

续接只在内存中保守缓存。进程重启、凭据／请求头变化或序列化不匹配会全量重建。不跨重启恢复 socket，也不恢复正在执行的半条生成。诊断记录不是持久会话历史，完整对话仍在 DSH 中。真实账号和浏览器实际呈现验收必须与模拟、组件验证分开报告。禁用 bundle 或选回原提供商即可回滚。

## 从 0.3 升级

保留已有独立路由和凭据。会话请求现在默认保留连接并尝试精确增量；设置 `reuseConnection: false` 和 `continuation: false` 可恢复单次请求行为。同次 SSE 回退成功的 WS 故障现在累计冷却，认证故障不累计。截断生成报告未知结果，而不是瞬时传输重试。升级前将 `retryPolicy.mode: always` 或不安全重试码列表改成有限 normal 策略。不自动迁移提供商 ID 或会话数据。
